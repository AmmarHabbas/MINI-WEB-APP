# MINI Global Flagship — Standalone Pure HTML5 / CSS3 / Vanilla JS Edition

This directory contains a complete, self-contained, zero-dependency edition of the **MINI Global Flagship Website ("Big Love" & "Go-Kart Feeling")**.

## Features Included
- **No NPM or Build Step Needed**: Runs immediately by double-clicking `index.html` or hosting on any static web server (GitHub Pages, Netlify, Apache, Nginx, or AWS S3).
- **240mm Circular MINI OLED Display**: Features 4 interactive MINI Experience Modes (*Go-Kart*, *Green*, *Vivid*, and *Timeless 1959*) with live synthesized Web Audio sound profiles.
- **Interactive 360° Configurator**: Smooth horizontal drag rotation, dual-zone exterior paint selection (British Racing Green, Chili Red, Sunny Side Yellow, etc.), and signature Multitone Gradient roof.
- **Model Fleet Showcase**: Comprehensive specifications for the All-Electric MINI Cooper, Countryman ALL4 SUV, and John Cooper Works track edition.
- **Go-Kart Test Drive Booking**: With client-side `localStorage` persistence and confirmation ticket generation.

## How to Run
Simply open `index.html` in any modern web browser (Google Chrome, Apple Safari, Mozilla Firefox, Microsoft Edge). No server installation or node_modules needed!
